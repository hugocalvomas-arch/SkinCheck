# SkinCheck

Herramienta B2B de consejo dermocosmético para farmacias independientes: cuestionario + análisis de foto con IA, rutinas con el stock real de la farmacia (CSV del programa de gestión), hoja de consejo, recordatorios de reposición y panel del titular.

Stack: Next.js · Supabase (UE) · Vercel.

- `data/catalogo.json`: catálogo exportado de hugosbeautyproject (`scripts/exportar_catalogo.py`).
- Variables de entorno: ver `.env.example`.
